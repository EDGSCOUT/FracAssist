# 股骨颈骨折辅助诊断系统

## 项目简介

这是一个最小实现的股骨颈骨折辅助诊断系统，支持医学影像导入、关键点标注、角度计算和术前固定建议。

## 主要功能

1. **图像导入**：支持导入DICOM/NII导出的二维图像（JPG、PNG、TIFF等格式）
2. **关键点标注**：在图像上手动标注骨折近端和远端点
3. **角度计算**：基于标注点自动计算骨折线角度
4. **固定建议**：根据角度自动给出术前固定方案建议

## 系统要求

- Python 3.7+
- 操作系统：Windows/macOS/Linux

## 使用说明

### 1. 导入图像
- 点击【导入图像】按钮
- 选择医学影像文件（支持JPG、PNG、TIFF等格式）

### 2. 标注关键点
- 在图像上点击第一个点：骨折近端点（显示为红色）
- 在图像上点击第二个点：骨折远端点（显示为蓝色）
- 系统会自动绘制两点之间的连接线

### 3. 计算角度与建议
- 标注完成后，点击【计算角度与建议】按钮
- 系统会计算骨折线角度并在右侧显示分析结果
- 根据角度自动给出固定方案建议：
  - 近水平骨折（<30°）：倾向平行三钉固定
  - 中等角度骨折（30°-60°）：倾向交叉固定
  - 陡峭骨折（>60°）：倾向平行三钉固定（加强版）

### 4. 保存结果
- 点击【保存结果】按钮
- 选择保存位置，结果将保存为文本文件

### 5. 清除标注
- 点击【清除标注】按钮可以重新标注

## 角度计算原理

系统使用以下方法计算骨折角度：

1. 构建骨折线向量：从近端点指向远端点
2. 计算与冠状面法向量（垂直向下）的夹角
3. 转换为与水平线的夹角
4. 基于斜率判断骨折线趋势

## 固定建议规则

### 基于角度的建议

| 骨折角度 | 类型 | 建议方案 |
|---------|------|---------|
| <30° | 近水平骨折 | 平行三钉固定 |
| 30°-60° | 中等角度骨折 | 交叉固定 |
| >60° | 陡峭骨折 | 平行三钉固定（加强版）|

### 螺钉参数建议
- 螺钉数量：3枚
- 螺钉间距：10-15mm均匀间距
- 进钉方向：垂直于骨折线
- 进钉深度：避免穿透股骨头关节面

## 示例工作流程

1. 启动程序：`python fracture_assistant.py`
2. 点击【导入图像】，选择CT切片图像
3. 在图像上点击标注骨折近端点（红色）
4. 点击标注骨折远端点（蓝色）
5. 点击【计算角度与建议】
6. 查看右侧分析结果和固定建议
7. 点击【保存结果】导出分析报告

## 注意事项

1. 本系统基于二维图像标注，仅供参考
2. 实际手术方案应由专业医生根据三维影像和患者具体情况制定
3. 建议结合健侧对比进行更准确的评估
4. 标注点应准确反映骨折线的两端
5. 支持的图像格式：JPG、JPEG、PNG、BMP、TIFF

## 技术架构

```

├── FractureAssistant (主类)
│   ├── setup_ui()          # 设置用户界面
│   ├── load_image()        # 加载图像
│   ├── on_canvas_click()   # 处理点击标注
│   ├── calculate_and_suggest()  # 计算角度与建议
│   ├── generate_suggestion()   # 生成固定建议
│   ├── display_results()   # 显示结果
│   └── save_result()       # 保存结果
```
